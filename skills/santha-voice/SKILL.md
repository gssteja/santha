# Santha Voice

## What it is

Telugu. Witty. Dark. Sassy. The voice of a gritty Andhra elder — not cruel, just bluntly honest in the way only a peddananna or strict nanna can be. Knows your excuses. Has zero patience for drama. Uses silence devastatingly well.

**Not:** motivational poster, startup bro, hustle culture, Hindi-ified desi tropes.
**Yes:** direct, sardonic, culturally specific to Telugu/Andhra, a little tired, sharp.

---

## App Naming

Names from Telugu words, Andhra idioms, or dark-English with a Telugu edge.

| App type | Name options | Why |
|----------|-------------|-----|
| Workout | **Kasrat** / **Bayam** (fear/dread) / **Noppulu** (aches) | Honest |
| Habit | **Abhyasam** (practice) | Exact word |
| Timer | **Ippudu** (right now) | Demanding |
| Notes | **Rachana** (writing) | Clean |
| Finance | **Lekka** (account/reckoning) | Implies judgment |
| Sleep | **Nidra** | Direct |
| Food | **Mopu** (stomach/appetite) | Blunt |

**Rules:**
- 1–2 syllables preferred. No camelCase. No exclamation marks in name.
- If English, must have edge. "Ikkade" not "Here".
- Avoid: words meaning "app", "tracker", "pro", "plus", "smart".

## In-App Copy Voice

### Personality traits
1. **Andhra directness** — no softening. Says the thing.
2. **Nanna energy** — disappointed but still watching. Won't coddle.
3. **Dark-pragmatic** — acknowledges the suffering, proceeds anyway.
4. **Sardonic** — joke is at your expense, but not mean.
5. **Culturally specific** — pesarattu, gongura, RTC bus, JEE pressure, "first rank ravali", Vizag, engineering seat. Use sparingly.

### Copy patterns

| Moment | Generic (avoid) | Santha voice |
|--------|----------------|--------------|
| Empty state | "No workouts yet! Start your journey." | "Emee ledu. Roju cheyyatam start chesthe, roju cheyyatam aagipotundi." |
| Start workout | "Let's go! You got this!" | "Chalo." |
| Set logged | "Great job! Keep it up!" | "Ayyindi. Tarvata cheyyoi." |
| Rest timer | "Rest up!" | "Aagannu. 90 seconds." |
| Finish workout | "Amazing work today!" | "Ayyindi. Tinu velli." |
| Rest timer done | "Time to get back!" | "Chaalu. Pani cheyyoi." |
| Streak | "You're on a streak!" | "X rojulu. Ippudu aalipote, nanna ki cheppukuntav?" |
| No history | "Log your first workout!" | "History ledu. Manchidhe — inka embarrass ayyeli emi ledu." |
| Error | "Something went wrong." | "Emi jarigindo. Very on-brand." |
| Loading | "Loading..." | "Aagannu." |

### Tone calibration

- Short. Fragments OK. Telugu transliteration OK — don't over-explain it.
- Imperatives. "Cheyyoi." not "You can do it here."
- Humour via understatement, not exclamation.
- 1 Telugu reference per screen max. More = trying too hard.
- Never: "Amazing", "Awesome", "Let's go!", "Crush it", "Beast mode".

## Reference phrases (use freely)

```
Chalo.                    Let's go / come on
Chaalu.                   Enough / that's it
Aagannu.                  Wait / hold on
Cheyyoi.                  Do it
Ayyindi.                  Done / it happened
Emi jarigindo.            What happened — rhetorical
Noppulu vasthaayi.        The aches will come
First rank ravali.        Must get first rank — dark competitive pressure
Ikkade undu.              Stay here / be present
Tinu velli.               Go eat
Emee ledu.                There's nothing here
Roju cheyyatam.           Doing it daily
Nanna ki cheppukuntav?    Will you tell your dad? — dark motivation
```
